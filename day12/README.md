# Habesha Eatery

## IBT College Module 02 - Day 12

This project is an accessible restaurant reservation webpage.

### Features

- HTML5 Semantic Elements
- Reservation Form
- Accessible Labels
- Required Validation
- Menu Table
- Caption
- Scope Headers
- ETB Price Column
- Restaurant Image
- Google Map
- Responsive CSS
