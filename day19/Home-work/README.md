# Day 19 - DOM Manipulation

## Addis Market Shopping List

This project demonstrates JavaScript DOM manipulation and events.

## Exercises

1. Select and modify an h1 using textContent and classList.toggle.
2. Create Ethiopian city list items using createElement and append.
3. Demonstrate click events and event bubbling.
4. Delete list items using event delegation.
5. Submit a form and add the input to a list.

## Week-2 Project

The Addis Market application allows users to:

- Add shopping items.
- Enter prices in ETB.
- Delete items.
- Mark items as bought.
- Display a running total.

## How to Run

Open `index.html` in a web browser.
Open Chrome DevTools with:
F12
Then select the Console tab to see the event bubbling output.
