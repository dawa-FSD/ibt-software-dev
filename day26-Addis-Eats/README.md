# Addis Eats – Day 26

A simple static food menu built with Vite and React.

## Project Description

Addis Eats is a React application that displays a static menu of Ethiopian foods.

This project demonstrates the basic React concepts learned in the Day 27 in-class exercise.

## Requirements Completed

- Created a Vite + React project
- Created a reusable `Header` component
- Created a reusable `Dish` component
- Passed `name` and `price` using props
- Created a static array of dishes
- Used `map()` to render the menu
- Used stable `key` values for each dish
- Composed the `Header` and menu inside `App`
- Added CSS styling
- Committed the project to GitHub

## Features

- Addis Eats header
- Static food menu
- Reusable Dish component
- Dish name and price
- Ethiopian food menu
- Responsive and simple styling

## Technologies

- React

## Installation

Clone the repository and install the dependencies:

```bash
npm install
```

## Run the Project

Start the Vite development server:

```bash
npm run dev
```

Then open the local URL displayed in the terminal.

## Learning Goal

The goal of this exercise is to understand React components, props, arrays, `map()`, and keys while building a simple static menu.
