TeleBirr Transaction Report
A JavaScript mini-project that processes TeleBirr transactions using modern JavaScript.

Features
"filter()" — separates credits and debits
"reduce()" — calculates totals
"map()" — creates receipts
Destructuring and spread
ES Modules ("import" / "export")

Files
"transactions.js" — transaction data
"report.js" — report functions
"app.js" — runs the program
