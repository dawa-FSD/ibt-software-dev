# Day08 - Algorithms in Account Registry

## Goal
Practice Python algorithms by adding:
- Sorting
- Binary Search
- Recursion

## Features

### 1. Top Accounts by Balance
Returns the top n accounts with the highest balance.

registry.top_by_balance(3)
### 2. Binary Search
Finds an account by account number using Binary Search.

registry.find_by_number("CBE-001")
### 3. Recursive Total Transactions
Calculates the total of a transaction list using recursion.

transactions = [100, 200, 300]
total = registry.total_transactions(transactions)
print(total)   # 600
## Concepts Learned

- Sorting with sorted() and lambda
- Binary Search Algorithm
- Recursion
- Object-Oriented Programming (OOP)
