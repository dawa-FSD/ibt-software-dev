# Habesha Eatery Menu Card

## Objective

Create one styled `.menu-card` using:

- CSS Variables
- Box Model
- Typography
- Pseudo-class
- Pseudo-element

---

## Requirements

✔ Global reset with box-sizing:border-box

✔ Base font-family

✔ line-height

✔ Card padding

✔ Border

✔ Gold top accent

✔ Use var() for every color

✔ Hover effect

✔ Price uses ::before

✔ Zebra stripe ingredients with nth-child(even)
