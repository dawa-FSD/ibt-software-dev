# Addis Eats – Day 27

A simple static food menu built with Vite and React.

## Project Description

Addis Eats is a React-based static menu application for displaying Ethiopian food and other dishes.

This project demonstrates the basic React concepts learned in Day 27:

- Setting up a Vite + React project
- Creating reusable components
- Passing data using props
- Rendering a menu from an array
- Using `map()` to render multiple dishes
- Using stable keys for rendered components
- Composing components together

## Features

- Addis Eats Header
- Reusable Dish component
- Dish name and price displayed using props
- Static menu data
- Menu rendered using `map()`
- Stable `id` keys for each dish

## Technologies

- React
- Vite
- JavaScript
- HTML
- CSS

## Installation

Clone the repository and install the dependencies:

```bash
npm install
```

## Run the Project

Start the Vite development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Learning Goal

The goal of this project is to understand how React components, props, arrays, `map()`, and keys are used to build reusable user interfaces.
