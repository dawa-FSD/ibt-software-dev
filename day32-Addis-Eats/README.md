# 🍽️ Addis Eats

**Addis Eats** is a React-based Ethiopian food ordering application. Users can browse Ethiopian dishes, add items to a shopping cart, manage quantities, and complete checkout.

## ✨ Features

- 🍛 Browse Ethiopian foods
- 🛒 Add and remove cart items
- ➕ Increase and decrease quantity
- 💰 Calculate cart total
- 💾 Save cart data with LocalStorage
- 🔐 User authentication
- 🧭 React Router navigation
- 📱 Responsive CSS design

## 🛠️ Technologies

- React.js
- JavaScript
- React Router
- Zustand
- LocalStorage
- CSS3
- Vite
