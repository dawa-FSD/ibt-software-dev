# Country Facts Page

A simple JavaScript page that fetches country information from the REST Countries API.

## How to Run

Open `index.html` in a web browser.

## API

REST Countries API:

https://restcountries.com/v3.1/name/{country}

## Features

- Search for a country
- Shows loading state
- Shows country flag
- Shows capital
- Shows population
- Shows region
- Shows currencies
- Shows friendly error message
- Loads Ethiopia by default
