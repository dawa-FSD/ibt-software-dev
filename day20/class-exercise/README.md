# Fetch & Display Live Data

## API

JSONPlaceholder: `https://jsonplaceholder.typicode.com/posts`

## Requirements

- Show **Loading…** while fetching.
- Fetch JSON data using `async/await`.
- Check `res.ok`.
- Render the results inside `<ul id="list">`.
- Show a friendly error message if the request fails.
- Clear the loading state after the request.
- Refresh button is a bonus.

## Self-Check

- [ ] Data loads successfully
- [ ] Loading message appears
- [ ] Results display on the page
- [ ] Error message works
- [ ] Refresh button works (bonus)
